Personal site — deployment notes
================================

Files: index.html, photo.jpg, Disharee_Bhowmick_CV.pdf
All three must sit in the same folder.

1. Create a GitHub repo named:  Dzb0110.github.io
   (or reuse the existing MyWebsite repo and enable Pages on it)
2. Upload all three files.
3. Settings -> Pages -> Source: "Deploy from a branch", branch: main, folder: / (root)
4. Live in about a minute at https://Dzb0110.github.io

Everything is wired up: email, ORCID, LinkedIn, GitHub, research group,
STaTS (journal / arXiv / code), CVT-Bench (arXiv / project page), CV
download, and the photo.

Google Scholar is the only link still missing — there's a commented line
in the links row ready for the URL once you create a profile.

If photo.jpg ever fails to load, the page falls back to a "DB" monogram
rather than showing a broken image.
